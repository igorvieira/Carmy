# Carmy brand

> LLM reasoning can be probabilistic. Side effects should not be.

**Carmy: Composable Agent Runtime for Managed Yield**

The chef places one piece at a time, with tweezers, on a straight rail:

| element | meaning |
|---------|---------|
| the rail | the defined execution path |
| the red cube | the execution in progress |
| the gray pieces (cube, cylinder, pyramid) | tools that compose |
| the tweezers | precision and controlled side effects |
