# Carmy documentation

The documentation lives at **https://carmy-pi.vercel.app**, in English and Brazilian
Portuguese. Its sources are in [`website/`](../website), built with
[Starlight](https://starlight.astro.build).

| topic | page |
|-------|------|
| Architecture | https://carmy-pi.vercel.app/reference/architecture/ |
| HTTP protocol | https://carmy-pi.vercel.app/transports/http/ |
| MCP | https://carmy-pi.vercel.app/transports/mcp/ |
| Benchmarks | https://carmy-pi.vercel.app/reference/benchmarks/ |

To run it locally:

```console
cd website
pnpm install
pnpm dev
```
